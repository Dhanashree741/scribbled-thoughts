# ✍️ Scribbled Thoughts

A modern blogging platform built with Django that allows users to explore articles, create accounts, securely log in with Google, like posts, comment on blogs, and browse content by category.

🌐 **Live Demo:** https://scribbled-thoughts.onrender.com

---

## 🚀 Features

- User Authentication
- Google OAuth Login
- Create, Read, Update & Delete Blogs
- Blog Categories
- Like Posts
- Comment System
- Responsive Design
- Search Functionality
- Clean Bootstrap UI
- Django Admin Panel

---

- Django Authentication
- Django AllAuth
- Google OAuth 2.0

## ⚙ Installation

```bash
git clone https://github.com/yourusername/ScribbledThoughts.git

cd ScribbledThoughts

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
